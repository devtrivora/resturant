# 🍽️ Beresta

A modern, responsive, and beautifully designed web application for Beresta, an authentic Bengali restaurant. Built with React, this application showcases the restaurant's menu, chef details, gallery, and more.

## 🚀 Features

- **Modern UI/UX:** A stunning, premium design that provides an excellent user experience.
- **Responsive Design:** Fully responsive layout that looks great on desktops, tablets, and mobile devices.
- **Dynamic Content:** Showcases special menus, awards, and chef's word.
- **Image Gallery:** A beautifully styled image gallery for highlighting restaurant ambiance and dishes.

## 🛠️ Tech Stack

- **Frontend Framework:** [React.js](https://reactjs.org/)
- **Styling:** CSS3
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Deployment:** GitHub Pages

## 📦 Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites

Make sure you have Node.js and npm installed on your computer.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/devtrivora/resturant.git
   ```

2. Navigate into the project directory:
   ```bash
   cd resturant
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server, run:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will automatically reload if you make edits.

## 🚀 Deployment

This project is configured to be deployed on GitHub Pages. To build and deploy the app, run:

```bash
npm run deploy
```
